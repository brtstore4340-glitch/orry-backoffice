# Naming Conventions

- Match the naming style already present in the touched module.
- Route segments should follow Next.js App Router conventions already used in `src/app/`.
- Shared component files should stay descriptive and aligned to nearby component names.
- Domain terms should use ORRY business vocabulary already established in the repo:
  - billing note
  - cash invoice
  - tax invoice
  - receipt
  - purchase order
  - withholding tax
  - company profile
  - branch
- Avoid introducing alternate names for the same document type.
