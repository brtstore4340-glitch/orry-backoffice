# Thai Translation Governance

- Reuse the canonical terms in `src/lib/thai-terminology.ts`.
- Before changing Thai UI copy, check `reports/flowaccount-canonical-thai-glossary.md`.
- When the same concept appears in multiple screens, update the shared constant or label source first.
- Use FlowAccount only as terminology reference for accounting and menu concepts. Do not import FlowAccount branding, slogans, or product copy into ORRY UI.
- Prefer established Thai business terms over literal English calques when the FlowAccount domain clearly uses a standard Thai term.
